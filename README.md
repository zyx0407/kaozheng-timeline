## 自动化：官方源变化核对（只报告，不改数据）

## 分享（分享的就是整张卡片）

- **每张卡右下角有「分享」键** → 弹出的**是一整张分享卡**：报名时间 · 考试时间 · **费用** · **官方网站（带域名）** · 小鱼那句说明 · 右下角二维码，卡里还写了线上地址。**码是点的时候才生成的**（45 张卡不会一上来画 45 个码，页面不变重）。
- 弹层底下三个键：**保存图片**（手绘 canvas 存成 2 倍图 PNG，750×930 上下，**永远存浅色版**——发给同学、贴群里深色版不好读）、**复制链接**、**关闭**。
- **码里装的是「当前页面地址 + `?card=<这张证>`」**：手机扫开就**直接滚到那张卡并标亮**（`?card=` 用完会从地址栏收掉，用的是 `replaceState`，不刷新、不会丢你刚打的标记）。
- 链接跟着页面走：线上扫出来就是 `https://work1.zyx0407.com/?card=cpa`，本机就是 `http://127.0.0.1:5185/?card=cpa`。
- ⚠️ **弹层居中别用 `align-items:center`**：卡片和底下那排按钮必须**同一条中轴**。第一版就是栽在这儿（内容比视口宽时左半边被挤出可视区、拖不回来；读数里卡片中轴 416 / 按钮中轴 705，他直接看出来「下面的选项会偏移」）。现在的做法：`.shade`（flex）→ `.shade-inner`（`width:100%` + `margin:auto`）→ `#shareHost` 撑满整行再用 flex 居中卡片。`test\share-card-check.mjs` 会量两个中轴是否相等（差 ≤1px）。
- **二维码是自己写的**（`app.js` 里的 `QR` 模块，零依赖）：只做够用的一档 —— 字节模式(UTF-8) + 纠错等级 M + 版本 1~10（版本 10-M 能装 205 字节，分享链接 40~90 字节）。里面是标准那套：BCH(15,5) 格式信息、GF(256) Reed-Solomon（本原多项式 0x11D）、8 个掩码按罚分挑最优。
- **怎么验的**：① `test\qr-decode.mjs` 是一份**独立写的解码器**（不抄编码器，自检含 32 张掩码×纠错档 + RS 注入纠错 + ISO 规范固定样例），`test\qr-crosscheck.mjs` 拿**参考库 48 条 + 我的 48 条**跑，要求**解出来和原文逐字节相等**（当前 **96 PASS / 0 FAIL**）；② **分享卡那条最狠**：`test\share-card-check.mjs` 把「保存图片」画出来的 canvas **逐模块采回矩阵**，再交给独立解码器解 —— 解出的必须正好是分享链接（证明**存下来的图真能扫**）；③ 另有 `?qrselftest=1` 结构自检（尺寸/定位图形/定时图形/固定深色模块/深色比例）。
- ⚠️ **三个坑（都会让码直接扫不出来）**：`RS 块结构表`不能凭记忆写（v3 是 1 块×44，我错写成 2 块×22；v5–v10 也错）→ 权威来源是 Python qrcode `base.py :: RS_BLOCK_TABLE`；位流顺序必须是「模式 0100 → 计数 → 数据」；**格式信息两份拷贝的位序方向相反** → 照 `qrcode/main.py :: setup_type_info`。
- 判据注意：参考库对 v3 会**选不同掩码**（罚分算法不同）→ 只要求「解码器能解出原文」，不要求与它逐模块相同。

## 时间轴为什么是「滚动事件钉住」而不是 `position: sticky`

一开始用的是 `position: sticky`，但在这张页面里它**只吸一截就跟着走**（CDP 实测 `top=-2411`）。逐层排查过：祖先链上没有 `transform` / `filter` / `will-change` / `contain`，`overflow` 全是 `visible`，包含块有 1.9 万像素高，视口高度也换过三种——都没用；而同一个最小复现页在同一套无头参数下**吸得好好的**。查不出破坏者，就不跟它耗了：

- 改成 `app.js` 里用滚动事件 + `position: fixed` 自己钉（`rAF` 节流，只在跨过界线时才改样式）；
- 判据很清楚：**条顶撞到视口顶之后钉住，到清单区底部就松手**（不盖页脚）；
- 行为有实测守着：`test\pin-check.mjs` 会真滚一次，量钉住位置、左右对齐、横向滚动、松手与重钉。

## 数据规矩（改 `数据.js` 前先看这段）

- 一条证 = 一个对象；`报名时间` / `考试时间` 都是**数组**（一年两次就写两条）。
- **`说明` 一律写成「小鱼：」开头的口吻**（他 2026-09-27 定）：对着同学讲人话、给一句能用的判断（什么时候考、卡什么条件、哪个坑别踩），**不写官方介绍腔**，也不要用 Markdown 记号（数据是纯文本）。
- `来源` 只能写 `"官方"` 或 `"往年规律"`；写「往年规律」**必须**给 `备注` 说明按哪年推的。
- 查不到官方公布的确切日期 → `未公布: true`，日期写去年同期并在备注里写「参考 XXXX 年 X 月，待官方公布」。
  **不许编造精确日期。**
- 每条都要写 `数据截至`（页面上会显示，读者据此判断新旧）。
- `官网` 必须是官方域名；`test\smoke.mjs` 会把培训机构域名（新东方 / 东奥 / 环球…）直接判错。
- 时间轴窗口 = `元信息.时间轴起点` 起 12 个月；库里数据铺到 `元信息.数据铺到` 那个月（滚过去能看到）。

## 页面怎么用

- **轴**：12 个月格子（吸顶条），格子里写「**报 N · 考 N**」——N＝这个月有几条在报名窗口里 / 有几个考试日；底沿一条中性密度条。当前月＝一条琥珀线 + 琥珀数字。点一下滚到那个月的分组。
- **卡片**：**按月分组**（左边一个大月份编号；组内先按类别、同类里「最近要有事的」排前面，跟卡上那句倒计时对得上）。卡面＝顶行（证名 + 简称 + 类别 + 倒计时）→ 三块事实（报名窗口 / 考试日 / 费用）→ 官网站点 → 适合谁 → 小鱼那句 → 底行（数据截至 · 官网核对 · 状态 · 分享）。日期**一律带年份**（多批次才不会糊成同一天），第二批及以后的日期压暗一档。
- **筛选**：类别（全部 + 7 类：语言 / 计算机 / 财经商科 / 食品与营养 / 教师资格 / 技能新兴 / 出国）· 状态（全部 / 未标记 / 准备 / 已拿 / 不考）。
- **状态标记**：卡片右下三枚按钮，点一下标记、再点同一个取消；存 `localStorage`（键 `kaozheng.status.v1`），**只在本机浏览器**，清浏览器数据就没了。
- **倒计时**：取**最近的那一场**（不是数据里写在前面的那场——CET 口语 11-21 排在笔试 12-12 后面，按顺序取会报成「还有 76 天」）。文案：报名还有 N 天 / 报名中 / 考试还有 N 天 / 本次已结束。
